# ZALAM AI

Independent open-source AI workspace foundation.

Status: early scaffold, not production-ready. Chat, model discovery, basic health reporting, and CI configuration are present. User accounts, durable chat history, agent tools, file processing, research, media generation, MCP integrations, authorized security-lab execution, and benchmark suite are not yet implemented or verified.

Keep all credentials in server-side environment variables. Do not commit secrets. Security testing is limited to systems you own or are explicitly authorized to test.
